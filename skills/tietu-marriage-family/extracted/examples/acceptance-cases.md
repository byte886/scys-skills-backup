# 验收案例

## 无 Skill 基线：中年夫妻无话可说

通用写法容易把一次餐桌沉默扩成“女人需要沟通、男人只会逃避”，固定沙发和手机场景，编造 18 年婚姻与自动和好，再用“真正好的夫妻从来不是……而是……”收尾。它看似完整，实际缺少来源、边界和具体行动。

本 Skill 要求：

1. 标题有婚龄、家庭动作或关系节点，避免性别群体口号。
2. 正文先写可见动作（递作业本、收碗、等家长会），不替双方读心。
3. 只留一个情绪，承认冲突和未解决处，不命令离婚或复合。
4. 首图标题、第二图关系证据；故事多图只在有连续时间节点时申请。

## 通过案例：餐桌十分钟

素材只提供“结婚17年、孩子上初中、父亲先问作业”。可以写餐桌、作业本、手机和一次请求；不能补出轨、跪地、谁更自私或自动修复。结尾落在“先把今天发生的事讲清楚”。

## 通过案例：边界与安全

涉及威胁、暴力、未成年人安全时，不做婚姻诊断和调解承诺，建议寻求当地专业机构帮助；不公开姓名、学校、住址等可识别信息。

## 通过案例：完整故事

有明确的晚饭→家长会→楼道谈话→第二天回应四个节点时，可用 `real_life_sequence` 的 4 张图；理由要说明两张无法呈现时间与回应变化，不能写“更丰富”。
