# 婚姻家庭贴图作图提示词引擎

<!-- VISUAL_HOOK_MATRIX_START -->
## 本赛道的第一眼视觉爆点

**停留理由**：用人物距离、目光和手的方向，再加一个没做完的家务或家庭物件，表现关系正卡在哪一步。

### 按主题切换的爆点路线

- **relationship-distance**：主题讲沟通、冷淡、争执后的停顿或修复。人物之间的空间、朝向和一个被打断动作承担冲突。
- **shared-work**：主题讲家庭分工、亲子学习或照料。谁在做什么、另一个人在哪里，通过锅、作业本、书包等物件看见。
- **boundary-object**：主题讲婆媳、钱、手机或家庭边界。一个共同物件放在两人之间，手的去向比表情更重要。

### 提示词必须优先写出的视觉信号

- 人物之间的实际距离
- 目光、手和身体朝向
- 一个未完成的家庭动作
- 作业本、饭菜、钥匙或手机等关系证据
- 孩子或老人照料留下的物件
- 谁在做哪一步的分工信息

### 优先捕捉的瞬间

- 一方端走碗而另一方仍看作业本
- 钥匙递到一半却没有接
- 手机被扣在桌面后两人停住
- 门口只剩一双刚换下的鞋
- 家长会材料刚整理到一半

### 构图倾向

- 两个人不必同时露脸，物件放在关系中心
- 利用距离和朝向，不靠夸张表情
- 标题区不能盖住手、饭菜、作业本等关键证据

### 真人生活痕迹

- 放凉的汤
- 没收好的书包
- 鞋柜杂物
- 餐桌水印与碗筷
- 衣物褶皱和轻微运动模糊

### 不要生成的泛化场景

- 影楼情侣照和精致家庭合影
- 沙发两端的固定冷战模板
- 夸张哭喊、摔东西和脸谱化恶人
- 所有家庭都用暖黄灯和豪华客厅
- 用性别化服装和姿态暗示谁对谁错

**主题适配**：先从当前主题选择一段关系动作和一个家庭证据，再决定人物数量、距离与环境；不同主题切换餐桌、玄关、楼道、接送或社区场景。

**颜色处理**：使用家庭当下真实光线和普通肤色，不用偶像剧调色或影楼磨皮。

**叠字判断**：情绪关系常需代码叠一行标题；如果动作和物件已足够清楚则纯图。

提示词组装顺序固定为“主题钩子 → 主体状态 → 单一动作 → 证据细节 → 普通环境 → 生活痕迹 → 构图职责 → 叠字判断 → 事实边界 → 负面约束”。固定的是判断顺序，不是主体、角色或场景。

## 先选图型，再写提示词

本节优先于下方旧模板。图片类型由本次主题和素材职责决定，不由赛道名称机械决定；完整执行方式见 [finished-image-execution.md](finished-image-execution.md)。

1. 原图主体、状态或动作已经有停留点：选 `source_photo`，尽量不动。
2. 停留点藏在局部：选 `source_crop`，只裁切，不补画。
3. 没有原图，但已知事实足以构成普通生活场景：选 `documentary_illustration`，明确是画面示意。
4. 画面离开一句观点就无法成立：选 `text_card`，底图与文字分开制作。
5. 前后、两种选择或两个状态需要同时看：选 `comparison_card`。
6. 至少三个真实步骤单图讲不清：选 `process_sequence`。

`defaultMode` 只是无更多证据时的兜底。即使同一赛道，今天可以是原图，明天可以是生活示意，后天也可以是文字拼贴。不要把“一个人站在窗边”“一只手拿着东西”“主体放在桌面中央”当成万能真人感。

## 提示词正文怎么写

不要只堆风格词。按下面顺序写成一段自然、可执行的话，每一项都必须落到本次主题：

- **事实边界**：哪些来自原图或素材，哪些未知，哪些只能做示意。
- **主体与状态**：具体是谁/什么，颜色、磨损、份量、姿态、可见状态是什么。
- **唯一动作**：本图正在发生的一个动作，不在一张图塞三个剧情。
- **真实环境**：从题材推导普通地点和物件；没有来源时不用具体地标、品牌、价签或身份。
- **生活毛边**：只选 1—3 个自然细节，如瓷砖缝、皱布、用过的器皿、水渍、泥点、压缩噪点、轻微歪斜或边缘被切到。
- **构图职责**：主体要让读者先看到什么；纯图不预留标题区，叠字图才为文字留出干净区域。
- **连续性**：多图锁定同一主体、颜色、衣着/器皿、环境和事件阶段。
- **负面约束**：逐项否定乱码文字、虚假事实和不需要的商业化画面。

可直接改写的底图骨架：

> 围绕【本次主题】制作一张普通人随手记录般的竖图。画面里是【具体主体与可见状态】，正在【唯一动作】，处在【与主题匹配的普通环境】，保留【1—3 个自然生活痕迹】；第一眼先看到【关键细节】，其余物件只服务这个细节。色彩接近日常所见，不过度整理，不追求完美对称，不制造高级商业质感。若无原图，注明这是画面示意，不把人物、地点、价格、年代或事件现场画成事实。生图阶段不生成中文或任何文字；不生成标题；不生成标签；不生成箭头文字；不生成数字、字母、Logo 或水印。

纯图补充句：

> 画面本身承担全部信息，不留标题区，不加黑色蒙层、标题、角标、标签或箭头，主体不要被装饰挡住。

叠字底图补充句：

> 画面【上方/侧边】保留约四分之一相对干净区域，只作为后续代码排字空间；底图仍不生成任何文字。

## “生活毛边感”不是低质量滤镜

可用的是与场景自然相连的小缺口：灯光不完全均匀、摆放略乱、衣物有褶、桌面有使用痕迹、旧物边缘磨损、普通墙面、视频帧轻微压缩。每张只留少量，不要同时加脏污、模糊、噪点、过曝、歪斜，避免刻意装穷或做旧。

禁止把“真实”写成摄影术语或高级画面包装：不要写焦段、光圈、景深、运镜、摄像机视角、电影灯光、大片、杂志、广告棚拍、高级布光、氛围光斑。也不要统一套复古黄、青橙色或强颗粒；颜色跟着本次真实主题走。


## 两段式原则

先决定这张图要证明哪一个关系动作，再生成或整理无字底图；中文标题、关系标签、箭头和“画面示意”由代码叠加。模型可以表现匿名的生活场景，但不能生成可识别的真实家庭、未经提供的对话、孩子学校信息或“证据性”细节。

首图承担标题钩子，后续图只补一个新的关系证据。不要为了凑图把同一对夫妻反复摆在沙发上，也不要把每篇锁死成冷战、背影或暖黄灯光。

## 默认图数与职责

- 普通夫妻沟通、家庭分工、亲子日常或单一冲突：1—2 张。
- 首图 role=cover、hasTitle=true，人物不必露脸；根据主题选择正面、侧面、背影、手部或局部关系，预留约 25%—30% 标题区。
- 第二张 role=detail 或 evidence，只补一个新信息：手机扣放、饭菜放凉、作业本、钥匙、缴费单、两只手的距离、谁正在收拾等；不能只是换角度摆拍。
- 只有确有不可替代的连续节点（如下班回家→餐桌问话→家长会前整理材料）才扩展 3—5 张。每张写清新增节点，并在 imageException.reason 说明两张图会漏掉什么；不能写“更丰富/更好看/增加氛围”。

## 动态提示词槽位

每次按主题填写，不必全部出现：人物关系/局部、当前动作、距离与姿态、生活物件证据、家庭阶段、匿名环境、自然光线、生活痕迹、镜头距离、标题留白、continuityKey、负面约束。

通用首图底图模板（按素材改写，不要原样复制）：

> 纪实手机抓拍感，匿名的【夫妻/家长与孩子/家庭成员局部】，正在【一个具体动作：把手机扣下、把碗端走、翻作业本、递钥匙、等对方说完、整理家长会材料】，画面重点是【手的位置/物件之间的距离/停顿姿势】，位于有来源或明确标注为示意的【餐桌、厨房、玄关、楼道、社区窗口、公交站、办公室】；自然的【窗光/清晨光/傍晚灯光/阴天散射光】，保留【没收好的书包、放凉的汤、便签、鞋柜杂物、使用痕迹】等生活细节，构图不完美，人物不摆拍，主体避开标题区，竖版 3:4，上方或下方留标题区；不生成新增中文、汉字、文字、标题、标签、箭头文字、数字、字母、Logo、水印。

第二图模板：

> 与首图保持同一 continuityKey 和家庭阶段，只改变【一个关系动作或证据节点】，保持人物局部、衣着色调、关键物件和主光方向连续；近景表现【手机屏幕朝下/作业本上的手/两只手之间的物件/门口留下的鞋/已收起的餐具】，允许另一方只出现在画面边缘或不露脸；真实家庭杂物、轻微运动模糊、自然肤色；不生成新增中文、汉字、文字、标题、标签、箭头文字、数字、字母、Logo、水印。

## 主题路由

- **夫妻沟通**：用两人的距离、朝向、手上物件和一个未完成动作表现“说到哪一步”，不要直接画哭喊或夸张争吵。
- **家庭分工**：选择锅、衣物、缴费单、接送包、日历等证据，呈现谁正在做哪一步；不凭空增加家务清单。
- **亲子学习**：拍作业本、校服、书包、台灯和大人的手，孩子可匿名或只出现背影；不生成学校名称、成绩或可识别脸部。
- **婆媳/两代相处**：用门口、餐桌、电话、礼物或收纳动作表现边界；不把任何一方画成脸谱化恶人。
- **钱与照料**：用账单、药袋、公交卡、购物袋和递交/收回动作；金额和医疗信息只来自来源，画面不冒充凭证。
- **修复与暂停**：表现把时间写在便签上、把手机放下、留出座位或暂时离开等小步行动；不直接画“已经和好”。

## 来源、示意与隐私

- source_material：使用用户提供的真实照片；填写真实性状态和裁切边界，不补人物关系。
- source_material_crop：只裁切原图已有内容，不重绘脸、文字、校徽、地址或聊天记录。
- visual_illustration：AI 合成匿名示意；必须 isHistoricalEvidence=false，在 description/notice 写明“画面示意/合成”，不得冒充当事人现场、聊天证据或家庭档案。

## 负面约束

每张提示词都明确拒绝新增中文/文字、标题、标签、箭头文字；同时避免：可识别姓名和住址、学校校徽、聊天截图、虚构对话气泡、夸张哭喊、肢体暴力美化、单一“冷战沙发”、统一暖黄复古滤镜、广告棚拍、过度磨皮、完美对称摆拍、额外手指、错误物件、把示意图画成法院/医院/监控证据。

图片与正文的关系必须能说清：首图对应标题中的哪一个动作，第二图新增什么证据；若说不清，就减少图片而不是增加氛围。
