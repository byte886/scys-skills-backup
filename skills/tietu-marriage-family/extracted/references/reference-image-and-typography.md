# 参考图与文字排版

## 先让用户选择参考图怎么用

同一张参考图只走一种主路由，不擅自混用。

1. **原图使用 `use_original`**：用户确认图片为自有、已授权或允许复用时，直接使用原图；只做比例适配和必要排版，不重新生图。
2. **轻度变换 `light_transform`**：保留原主体和真实现场，仅调整裁切、比例、亮度、留白、局部清理或叠字。不得无故换人、换物、改事实。
3. **参考复刻 `style_reference`**：拆出构图、主体占比、动作、色彩、光线、生活痕迹和第一眼爆点，再围绕新主题生成相似气质的新图；不照搬可识别人物、品牌、原图细节或独特作品。
4. **寻找类似图 `similar_search`**：从参考图提炼“主体 + 动作 + 环境 + 质感 + 构图”的检索词，给出可核验来源与候选图，确认授权条件后再使用。

没有授权信息时，不把网络对标图默认当作可直接商用的原图；默认走“参考复刻”或“寻找类似图”。

## 五套文字样式

- `top-gradient`：顶部渐变大标题，适合长问题与观点入口。
- `white-bars`：白底条分行，适合实拍、怀旧和步骤信息。
- `outlined-center`：居中描边大字，适合短而强的停留标题。
- `keyword-accent`：第一行强调色，适合数字、关键词和判断题。
- `note-card`：下部生活便签卡，适合关系、成长与感悟。

渲染输入示例：

```json
{
  "title": "这句话为什么让人停下来？",
  "imagePath": "./base.png",
  "overlayMode": "title",
  "textStyle": "outlined-center",
  "textStyleOptions": {
    "placement": "top",
    "align": "center",
    "fontScale": 0.92,
    "titleColor": "#FFFFFF",
    "accentColor": "#FFB000",
    "cardColor": "#FFFDF8"
  }
}
```

`textStyleOptions` 只允许调整位置、对齐、字号比例和三种颜色。若参考图风格已经能由五套模板表达，优先只选择模板，不增加无意义的新样式。

## 把参考范例沉淀为可复用样式

1. 读取参考图，记录标题区域、对齐方式、行数、主次字号、文字色、强调色、描边或底板、图片留白。
2. 选择最接近的 `textStyle`，再用 `textStyleOptions` 保存差异。
3. 把配置保存到本技能 `assets/reference-layouts/样式名.json`，同时保存一张预览图和适用/不适用场景。
4. 后续只复用排版规律，具体标题、图片主体和赛道爆点仍跟当前主题变化。
5. 先用同一底图渲染预览；确认文字不挡主体、手机端可读、没有溢出，再用于批量成图。

参考图如果主要价值在图片本身，而不是文字排版，回到上面的四种参考图路由处理，不要强行沉淀成文字样式。
