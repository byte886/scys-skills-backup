# 公众号长文排版

这是写作包后面的最后一步：把已经写好的长文章排清楚，交出标题、排版正文和能打开的网页成品。它不负责换观点、补案例或创造内容。

## 先选样式

用户指定样式就照做；没指定时先按赛道选一个并说明，或在用户说“让我选”时给下面 5 项：

- 清爽蓝：个人 IP、方法和项目复盘；默认样式。
- 稳重绿：日常民生、退休生活、理性观点。
- 暖橙生活：柴米油盐、家常故事。
- 柔和紫：婚姻家庭、情感关系。
- 黑白素雅：沉静话题、纪念和克制表达。

整篇只用一种主色。老年读者正文保持 17–18px、行距宽松；其他文章以手机可读为准。不要满屏彩色字、卡片和分割线。

## 操作

1. 从写作包结果里取“最终标题”和“完整正文”，候选标题、素材缺口、自检文字不要放进可发布正文。
2. 只做短段落、自然小标题和少量重点句加粗；不擅自改原意、数字、时间、人称和结论。没有作者名、公众号名片或配图就不要编出来。
3. 将纯正文保存为 UTF-8 `正文.md`。小标题用 `## 小标题`，重点短句可用 `**重点**`；空一行分段。`[配图：...]` 只在用户要求留图位时使用。
4. 有 Python 3 时运行：

   `python3 scripts/render_article.py --title "最终标题" --body 正文.md --style 清爽蓝 --out-dir 成品`

   `--style` 可改为上面的另外 4 种名称。脚本不依赖额外库，会生成 `成品/标题.txt`、`成品/排版正文.md`、`成品/article.html`。若没有 Python 3，就按同样的结构直接生成一个自包含 HTML 文件，CSS 写在文件里，正文放在 `#article`，不要依赖外链或把代码块冒充网页。
5. 打开 `article.html` 检查手机宽度：标题、小标题、正文、强调和留白是否清楚，内容有没有丢失或重复。网页顶部有“复制正文”按钮；复制后粘贴到公众号后台，还要再用手机预览一次。后台可能吞掉部分网页样式，以后台预览为准手动微调。

## 最终交付

明确给用户最终标题、排版好的完整正文、可打开的 `article.html` 文件路径；有资料缺口则另附短说明，不混入正文。只生成本地成品，不擅自上传飞书、登录公众号、发布或替用户声明已发布。
