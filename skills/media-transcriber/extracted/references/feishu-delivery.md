# 可选：飞书文档交付

仅在用户要求或当前会话已有约定时启用。使用安装人自己的已授权账号，在当前授权范围内读取和交付文档。

## 读取来源

- 已有相应飞书技能/连接时，按当前 `lark-doc`、`lark-minutes` 或 `lark-vc` 能力读取。
- 只有 lark-cli 时，先查本机 `--help` 与当前身份状态，再选择命令；不照搬其他机器的 profile。
- 妙记优先读取完整文字记录。若得到智能纪要封面，读取其中明确关联的文字记录；无权限时报告缺口。
- 目录为空不等于文档为空，应读取正文。命令成功不等于逐字稿 ready，需检查业务状态和真实内容。

## 创建与验证

1. 先完成本地成稿与内容复核。
2. 用明确身份新建文档，默认标题以“整理稿：”开头；单独摘要或逐字稿使用对应标题，组合交付时标清各部分。用户要求更新某篇文档时按授权范围更新；源文档默认保留。
3. 长文用文件或结构化参数提交，避免把内容插进 shell 命令。lark-cli 参数以当前版本 `--help` 为准；若只接受相对 `@file`，在稿件目录执行。
4. 回读目录和正文片段，检查标题层级、首尾内容、加粗和写入完整性。
5. 核对接收者权限。创建账号能读取不证明用户能读取，需检查有效权限或接收者身份可访问结果。
6. 在既有授权范围内赋予目标接收者所需的最低权限；无权限授权时说明待办，不默认 full_access、组织共享或公网可读。

不因报错切换到另一个人的身份。创建返回不明时，先查目标文档或请求结果，避免盲目重试造成重复文档。

## 失败也交付已完成内容

在线创建失败或接收者访问未验证时，提供 Markdown 附件与短说明。权限解决后复用成稿，只补文档交付。

最终给可点击文档链接，不暴露凭据、签名媒体地址、授权回调或无关日志。
