# 音视频转录与长文整理 Skill

版本：1.1.0

技能标识：`media-transcriber`。

把视频、播客、会议录音或逐字稿变成可阅读的中文长稿：去口水话、去重复、校正转录错误、按主题组织，保留原意、案例、数字和推理过程。

默认交付完整中文整理稿。需要时可以增加简短摘要、带时间戳的整理稿或原始逐字稿；也可以明确只要其中一种。

这是供支持 Agent Skills 的 AI 助手安装的技能包，包含工作方法和辅助脚本。运行仍需要宿主 AI、文件/终端工具，以及按任务配置的媒体工具。它不包含独立聊天机器人、模型权重或账号凭据。

## 给朋友的最短用法

把整个 `media-transcriber` 文件夹或 ZIP 发给对方，对方可交给自己的 AI 助手并说：

> 请读取这个技能包的 SKILL.md 和 README.md，把它安装到当前助手的技能目录。先确认安装位置，保留已有同名技能。收到素材后先检查这次任务需要的工具，说明缺什么，再用“音视频转录与长文整理”处理。

如果助手不支持安装 Skills，也可以让它读取 SKILL.md 及按需读取所链接的参考文件；实际能否下载、转录和写文件取决于助手工具。

## 手动安装

解压后保持 `技能目录/media-transcriber/SKILL.md` 这一层结构，连同 `scripts`、`references`、`agents` 一起复制。

- Codex：按当前[官方技能文档](https://learn.chatgpt.com/docs/build-skills)，用户技能目录为 `~/.agents/skills/`。若现有安装由技能管理器使用其他目录，沿用其实际配置，不重复安装同名技能。
- Hermes：放在当前 profile 的 skills 目录。默认 profile 通常是 `~/.hermes/skills/`；独立 profile 使用自己的 skills 目录，或现有 `skills.create_dir` 配置。
- 其他助手：按产品的技能目录或导入功能安装，不只复制 SKILL.md。

安装后开启新会话，使用“音视频转录与长文整理”。有同名技能时先查看差异，不直接覆盖已有配置。

## 第一次使用

助手先根据素材检查需要的能力，并简短说明可以直接处理什么、缺什么、下一步怎样处理。已有逐字稿可以直接整理，不必为了用这个技能先安装语音模型。

本地检查命令在技能目录运行：

```bash
python3 scripts/check_environment.py --task text
```

| 当前要做什么 | `--task` 参数 | 检查重点 |
| --- | --- | --- |
| 整理已有文字 | `text` | 不把下载或 ASR 工具列为必需 |
| 处理字幕文件 | `subtitles` | 随包脚本使用的 Python |
| 从网站获取字幕或音频 | `url` | 本地 yt-dlp 路径；浏览器等宿主能力另查 |
| 本地语音识别 | `local-asr` | 当前 Python 中的转录库、媒体检查工具 |

如果工具装在独立虚拟环境，用该环境的 Python 运行检查。检查只读取工具清单，不安装软件、不下载模型、不读取账号凭据；检测到工具也不代表已经完成转录测试。模型是否已缓存、网站能否访问和飞书权限需在实际任务中核对。

助手没有终端时，应检查自己现有的文件、浏览器和转录连接。已有可用连接可直接使用，无需为了通过本地检查重复安装工具。

## 按需准备工具

| 任务 | 依赖 |
| --- | --- |
| 已有逐字稿整理 | 支持读写文件的 AI 助手，无需 ASR |
| 清洗 SRT/VTT/Whisper JSON | Python 3.9+，无第三方依赖 |
| 网站音视频或字幕提取 | yt-dlp；平台支持和登录条件以实际返回为准 |
| 检查、转码、切片 | ffmpeg/ffprobe |
| 本地音视频转录 | faster-whisper，或 Apple Silicon 上的 mlx-whisper |
| 飞书文档交付 | 自己已授权的飞书连接或 lark-cli；未配置时交付 Markdown |

依赖安装使用独立虚拟环境，避免修改现有 Agent 的运行环境。示例（macOS/Linux，Python 3.11）：

```bash
python3.11 -m venv .venv-transcription
.venv-transcription/bin/python -m pip install 'faster-whisper>=1.1,<2' 'yt-dlp>=2026.1,<2027'
```

Apple Silicon 如选择 MLX，可在独立环境安装 `mlx-whisper>=0.4,<0.6`；ffmpeg/ffprobe 按系统安装。Windows 虚拟环境解释器位于 `Scripts/python.exe`。

首次本地 ASR 可能需要下载模型，媒体在本地推理。长音视频的时间、内存和磁盘需求取决于硬件与模型，技能包不提供云服务额度。已有转录工具时可以直接使用，无需重复安装。

## 直接开始

**完整整理稿**

> 使用音视频转录与长文整理，把这个播客整理成完整中文长稿，保留案例、数字和推理过程：［单集链接］

**加简短摘要**

> 整理这段访谈，在完整稿前加一段简短摘要，帮助我先了解主要内容：［素材］

**带时间戳**

> 把这段录音整理成带真实时间戳的长稿，方便我回听核对：［文件］

**原始逐字稿**

> 只要这段录音的原始逐字稿，保留原语言和发言顺序，不删口水话：［文件］

**飞书交付**

> 把这个视频做成飞书整理稿，用我已授权的飞书账号创建新文档：［视频链接］

时间戳必须来自真实字幕或转录分段，没有可靠时间就如实说明。原始逐字稿会标明来源；自动识别结果不等于人工逐字校对，也不保证能区分说话人。

可先用一小段自己有权处理的音频验证：生成带时间的转录 JSON 和可读中文整理稿；如使用飞书，再确认接收者能打开文档。安装成功不等于所有平台和飞书授权已验证。

## 包内文件

- `SKILL.md`：技能入口与默认工作流。
- `references/writing-standard.md`：提纯与信息保留标准。
- `references/media-tools.md`：媒体获取、ASR 与排障。
- `references/feishu-delivery.md`：飞书可选交付流程。
- `scripts/check_environment.py`：按任务检查本地依赖，不安装或下载。
- `scripts/normalize_transcript.py`：规范化字幕/ASR JSON，生成文本与检查线索。
- `scripts/transcribe_local.py`：本地 ASR，保留分段结果。
- `agents/openai.yaml`：客户端显示信息。

本包包含通用的音视频转录和文稿整理流程，不包含账号密钥、个人聊天、历史转录、用户标识或私人文档链接。安装人使用自己的账户与权限。

## 验证范围

1.0.0 的已有记录包含技能结构校验、字幕清洗样例检查，以及临时合成音频的 faster-whisper CPU 转录与文本清洗；不能视为每次安装后的运行保证。

1.1.0 已通过技能结构、显示信息和相对链接检查。新增环境检查脚本通过当前环境文字整理、隔离环境的四种任务和无效参数六项检查；没有转录依赖时仍可整理已有文字，需要下载或转录时分别提示缺项。

依赖检查只验证工具是否可找到；实际长音频识别、各平台在线下载、MLX 分支及安装人自己的飞书权限仍需在目标环境验证。本轮没有重新执行音频转录。
