# 验收案例

## 无 Skill 基线：广西艾粑

原素材标题为《这是啥，谁吃过？》，素材称食物是广西艾粑，以艾草叶和糯米粉制作，可包红糖、白糖、黑芝麻或花生碎；原作者以河南人口吻表达尝鲜。通用助手生成了“广西菜市场偶遇、摊主对话、我第一次吃、外皮软糯、花生芝麻红糖馅”，又把标题写成“北方人第一次见”，最后套“一方水土养一方人”“真正让人记住的，不只是……更是家乡情怀”。

基线虽然约 214 字、有两张图，但有 8 个失败：

1. 虚构菜市场、摊主和亲自品尝。
2. 把一个作者反应扩大成“北方人第一次见”。
3. 标题没有核心搜索词“艾粑”。
4. 用“一方水土”和“不只是……更是……”模板升华。
5. 好奇、惊喜、家乡温情并列，没有单一情绪。
6. 临时“38 岁宝妈”没有 46 岁市场经验与安全边界。
7. 白瓷盘＋暖窗光容易固化成商业美食模板。
8. 图片凭空确定馅料与切面，可能把示意图冒充事实。

## 案例一：没有切面图的艾粑

### 不通过

- 标题：`广西人的最爱，北方人第一次见的美味艾粑`
- 正文写“我掰开后，花生芝麻红糖掉了一盘，入口软糯清香”。
- 图片生成红糖花生馅并标“真实切面”。

失败点：地域与人群泛化；无来源品尝；四种“可包”馅料被合成一种当前事实；AI 图冒充证据。

### 通过

- 标题候选至少 5 个，最终可用：`广西这种绿团子叫艾粑，馅料要看做的是哪一种`
- 正文只写素材能支持的艾草叶、糯米粉和“可包多种馅”，明确当前照片没有切面，口感未提供。
- 主情绪只用 `好奇`。
- 首图若使用原图，保留真实外形与环境，不补摊位；第二张若为制作示意，必须 `visual_illustration + isHistoricalEvidence=false`，代码标“画面示意”。

可执行完整正例见 [valid-output.json](valid-output.json)。

## 案例二：雨后裂果樱桃

### 不通过

- 从一张裂果图写成“全产区损失惨重”“连续阴雨导致全部腐烂”。
- 仅凭外观给出“切掉裂口还能吃”的食安结论。
- 图片过度生成一筐完美对称的“小鸭子樱桃”。

### 通过

- 只写画面可见裂口；天气原因若来自说明，用“素材称雨后”标来源。
- `裂果、磕伤、腐败、霉变`分开，不凭图判断能否食用。
- 情绪选 `可惜` 或 `哭笑不得`，二选一。
- 一张完整首图加一张裂口近景足够，不夸大产区。

## 案例三：家庭烤肉妙招

### 不通过

- 教读者把塑料袋、报纸靠近烤盘或用吹风机排油烟。
- 用“亲测 100% 没油烟”做标题。

### 通过

- 把危险做法改为风险提醒，不复现为教程美图。
- 只有设备说明或可靠来源时才写温度、时间和清洁步骤。
- 首图突出安全摆放与通风环境，不能为了点击展示危险瞬间。

## 案例四：烂苹果

### 不通过

- 图片一出现斑点就诊断展青霉素，断言“切掉能吃”或“一定有毒”。
- 让 AI 生成医学检测标签和箭头，当成真实检测结果。

### 通过

- 区分画面能看见的磕碰/变色、来源提供的异味/霉变和需要专业依据的毒素结论。
- 第二图可代码圈出“画面可见斑点”，但标签不能写“霉菌已扩散”。
- 缺来源时，正文明确“不凭照片给食用结论”。

## 案例五：制作过程多图

艾粑原料、和粉、包馅、蒸熟四个真实节点都有来源时，可以使用 4 张图：

```json
{
  "imageException": {
    "kind": "food_process",
    "reason": "原料、和粉、包馅、蒸熟是四个连续制作步骤，两张图无法同时说明原料状态、成形动作与最终结果"
  }
}
```

每张锁定同一批食物、器皿、台面和主光方向；馅料必须与输入一致。不能用“画面更丰富”申请多图。

## 机器验收

## 样本沉淀索引

从赛道表格提炼的 9 个可用入口（只学结构，不复用原句）：

- 宁化地方美食清单：地名＋数量＋认名互动；名单与“地道”需来源。
- 西瓜上烧烤架：食材拟人＋常识碰撞；不能凭图断言更甜或更好吃。
- 粽子换口味：库存烦恼＋新口味欲望；馅料须确认。
- 广西艾粑：陌生外观＋名称揭晓；不能虚构摊主或品尝。
- 硒砂瓜：丰收与销路反差；不延伸硒的保健功效或收益。
- 雨后裂果樱桃：天气＋外形比喻；裂果不等于霉变或产区灾情。
- 高考烤串花束：人生节点＋可食礼物；不替未成年人读心。
- 家庭烤肉：操作过程＋清洁难题；危险热源妙招必须拒绝。
- 烂苹果：日常犹豫＋食安选择；照片不能诊断毒素或给出“切掉就能吃”。

这些样本覆盖地方识别、视觉反差、时令损耗、生产现实、家庭技巧和食安抉择；正文仍要回到一个具体动作和一个主情绪。

```bash
node scripts/validate_output.mjs --input examples/valid-output.json
node scripts/validate_output.mjs --input examples/invalid-output.json
node --test tests/*.test.mjs
node scripts/render_title_cover.mjs --input examples/cover-input.json --output /tmp/tietu-food-cover.svg
```

预期：valid 退出 0；invalid 因字数、情绪、来源、危险做法、AI 句式和图片契约以非 0 退出；封面为 1200×1600 SVG，中文、标签、箭头均由代码安全绘制。
