# 核心提示词密封与可调参数

## 结论

本地 Codex Skill 无法同时做到“模型能读取完整提示词、用户能调整、但有本地文件权限的人永远看不到提示词”。模型要执行明文规则，运行时就必须获得明文；Base64、密码 ZIP 或把密钥与密文放在同一包里只能混淆，不是真保密。当前包保留明文 references，适合内部使用和继续修改。

## 公开网页的密封模式

对 贴图号·美食特产（food-specialty），把核心提示词放在服务端，例如 Cloudflare Worker；浏览器和公开 Skill 只提交本包 [assets/adjustment-schema.json](../assets/adjustment-schema.json) 允许的参数。Worker 在服务端拼装提示词，再调用模型，返回成稿、拆解和字段级失败原因，不返回 assembledPrompt、系统提示词或密钥。解密密钥若使用密文存储，只放 Worker Secret。

允许调节语气、长度倾向、主情绪、标题结构、场景关注点和图片数量；不允许覆盖事实边界、来源标记和高风险规则。日志只记录 requestId、版本、耗时、模型和脱敏错误。

## 不能承诺的部分

后端管理员、部署权限持有人以及收到完整请求的模型供应商，仍可能在其权限范围内接触运行时提示词。不要把公开前端里的 AES、Base64、压缩、字符串拆分或隐藏 DOM 说成不可见加密。
