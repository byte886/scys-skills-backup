# 真人活感与去 AI 味

## 先反应，再判断

正文可以从“我看到/读到后的反应”切入，也可以从动作、名称、价格或一个疑问切入；下面只是可选顺序，不是每篇都要执行。可以愣一下、认错一次、改口一次：

- `我第一眼把它认成青团，放大后才发现边上有艾草叶筋。`
- `看着有点怪；再看焦边，我又有点想尝，但素材没说味道。`
- `我原想写“这就是当地人都爱吃”，想想还是收回来，眼前只有这一份。`

这些是观察者的即时反应，不是把陌生人的照片偷换成作者亲历。没有来源时不能写“我买回家”“摊主告诉我”“我小时候吃过”。

## 细节密度

细节密度跟着素材走：每个自然段尽量落一个当前食物专属的动作、物件、声音或状态，例如盘边的花生碎、刀切过的黏连、烤架上的油滴、筐底的泥、称杆轻轻回弹。素材没有就不硬造；允许留一个不服务结论的小动静，避免所有细节都像为观点准备。

短句和长句交替，允许一句没说完或轻微自我修正；不靠故意错别字、连续“呀/哈哈哈”或满屏感叹号伪造真人。

## 高风险 AI 句式替换

| 不要这样写 | 改成什么 |
| --- | --- |
| 真正的美味从来不是食材，而是家的味道 | 写清掰开后的切面、馅料和当下疑问 |
| 这不仅是一道美食，更是一种文化传承 | 写谁在何地用什么原料做了哪一步；无来源就删 |
| 一方水土养一方人 | 写具体地方叫法或同一食物的做法差异 |
| 舌尖上的乡愁、治愈了所有疲惫 | 停在一个味觉条件或动作，不替读者感动 |
| 色香味俱全、令人垂涎欲滴 | 写焦边发亮、汁水、颗粒或盘边痕迹 |
| 网友纷纷表示、大家都说好吃 | 只引用有记录的评论，否则改成开放问题 |
| 作为北方人/南方人 | 删除群体对立，写“这张图里/素材说明中” |
| 愿大家都被美食温柔以待 | 用“你们那儿通常蒸着还是煎着？”收住 |

## 单一情绪闸门

先从 `好奇、馋、惊讶、可惜、心疼、犹豫、佩服、松一口气、哭笑不得` 选一个。若段落出现另一个情绪，问它是否必要；通常删掉第二个，别用“温暖、感动、乡愁”包住所有内容。视觉猎奇不要强行转人生比喻，食安提醒不要用恐吓代替说明。

## 人工检查清单

- 第一段是否有即时反应而不是先下结论？
- 是否区分看见、来源陈述、推测和品尝？
- 是否至少有一个食物专属动作/细节和一个生活杂音？
- 是否删掉绝对化、排比、PPT 小标题、假引语和模板祝福？
- 结尾是否停在食物选择/做法/待核实点，而不是万能升华？
