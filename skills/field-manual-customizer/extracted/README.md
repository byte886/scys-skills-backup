# 实战手册定制 Skill

版本：0.10.1

技能标识：`field-manual-customizer`。

适合有具体目标、愿意澄清影响路线的条件，且能读取自身生财资料的会员；也适合有旧手册要调整或更新的人。按目标、阶段和投入，用生财 MCP 整理站内实操经验；平台官方帮助可补操作路径和规则。单题问答直接回答，本技能不代操作账号；没有站内读取权限时只能在已有材料范围内处理，明确缺口。本地保留 Markdown 源稿与离线单文件网页，主要交付能自动生成时的 PDF，说明操作依据、关键缺口和实际验证范围。

## 开始使用

把完整文件夹交给支持 Agent Skills 的助手，按该客户端现有技能目录安装；保留已有同名版本，不只复制 SKILL.md。开启新会话后使用。`manifest.json` 用平台正式目标名 `claude_code`、`codex` 声明这两个客户端。

| 需要什么 | 用途 | 没有时 |
| --- | --- | --- |
| 用户自己的生财 MCP | 新检索站内来源 | 无法新取站内材料；可在现有材料范围内调整旧稿，说明限制 |
| 文件读写 | 保存手册与证据 | 当前客户端无法交付本地文件 |
| 终端与 Python 3.9+ | 下载图、运行文件检查 | 不下载受限图；按[人工核对清单](references/manual-review.md)核内容并标“文件检查未运行” |
| 网页搜索或已授权只读浏览器 | 核官方规则、补官方操作路径 | 缺口明确标出，不猜按钮 |
| Chrome、Edge 或 Chromium | 自动将离线网页打印为 PDF；也可打开网页手动打印 | 仍交付 Markdown 与 HTML，写明“PDF 未自动生成” |
| 已授权的飞书连接 | 上传 PDF 供手机阅读并回读确认 | 只交付本地 PDF 文件 |

连接验证只证明实际测试过的接口和资源可读，不代表全部来源权限。普通会员没报名时，问答和作业不能读；航海手册按实际返回处理。禁止改用内部服务或绕过权限。

## 示例请求

| 请求 | 举例 | 处理范围 |
| --- | --- | --- |
| 从零定制 | 我想做小红书实物电商，本金一万，一个人全职，先帮我完成第一次商品上架 | 补齐影响路线的信息，按目标组织 |
| 调整时间 | 这份手册改成每天晚上只有一小时，其他条件不变 | 复用资料，改受影响动作和进度 |
| 更新旧稿 | 把这份手册过期的规则和最近三个月的变化更新一遍 | 留旧稿，核变化，更新正文及相关引用 |
| 示例手册 | 我想了解 X AI 自媒体，先按新手做一份，其他你定，假设写清楚 | 使用明确的示例条件，不冒充真实个人情况 |
| 指定格式 | 给我一份可分享的 PDF | 能找到 Chrome、Edge 或 Chromium 时自动生成 PDF；失败时说明原因并保留网页“分享”按钮 |

可复制的最小输入：

> 我要完成的事与目前进度：____；可用时间和预算：____；地区与账号资格：____；已有手册或材料：____。空项可以留白，助手只追问会改变路线的条件。

跨客户端启动句：请根据我的目标和条件，使用“实战手册定制”整理有依据的步骤，先给我看目标、必需动作提纲和阻断缺口，再交付 PDF，源稿与离线网页留在本地。

## 交付什么

先判断是按某位会员条件定制，还是写给一类读者的通用版；不明确且影响路线时先问。定制版可对读者说“你”，通用版写读者画像和条件变化时的调整方法，用客观祈使句。开头顺序固定：模板自动生成的目录在最前；源稿以阅读说明开头，紧接按周或阶段的路线图（每一步可点到章节，表下写这一阶段先不做什么、以后再看什么），然后才是目标与条件；源稿不手写目录。关键条件澄清后先给简短提纲和阻断缺口，便于及早纠正方向。核心步骤有依据；没有可用截图时先判断原创示意或虚构样例是否能解释动作，文字足够时记下理由，连路径也缺依据时明确部分完成。

正文按实际前置条件排序，每步用一句话目标、3–5 条动作清单和做完的标准，长段拆短。可用案例写成含起点、做法、自述结果、来源的案例卡，吸收素材已有的总结性做法，给出带虚构占位的可套用模板，不把有效素材压成过短摘要。定制版进度适配可用时段和总时间。来源、规则和待核问题保留在附录，关键缺口同时在受影响步骤前提示。局部更新附变更说明。

本地保留 `手册.md` 和 `手册.html`，主要交付自动导出成功的 `手册.pdf`；需放到飞书给手机阅读时只上传 PDF。复制 [网页模板](templates/manual.html)，只填内容，不重写样式和脚本；按[网页交付步骤](references/web-delivery.md)检查目录、折叠、清单勾选、全文搜索、打印、链接与图片。正文图片可点击或用 Enter/Space 在页内放大，作者头像不参与；关闭后焦点回到原图，打印/PDF 中不显示放大层。搜索与导出位于标题之上；搜索显示所有精确子串命中、上下文及当前序号，点结果可展开章节并定位临时高亮，不筛掉正文；上下键及上一处、下一处按钮逐处跳转，回车跳转、Esc 关闭列表。HTML 的 CSS/JS 与小图都可内嵌，没有外部资源请求；来源外链只在读者点击时导航；正文 `[O1]`／`[S1]` 标记点到文末来源条目，文末“回到正文”点回首次引用，多来源合成一个标记组，网页与 PDF 均核跳转。为自动 PDF 优先内嵌全部图片；如果用相对路径的 `images/` 附件，需随 HTML 一起交付并走手动打印。自动 PDF 成功后，脚本只把 PDF 文件名写回网页；此时唯一的“分享”按钮复制网页所在文件夹路径并显示弹窗，复制失败可在弹窗中手动选取路径；弹窗另有可复制的提示词：请用户自己的 AI 先把 PDF 文件本身复制到剪贴板，无法复制时再打开文件夹并选中文件。未自动生成 PDF 时，按钮和原有两行提示照旧打开浏览器打印；读者选“存储为 PDF”，并关闭页眉和页脚。

案例作者头像仅在同一条 `topicDetail` 返回顶层的 `topicUserDTO.avatar` 和昵称均有值时，把整条原始返回交给 `scripts/embed_avatar.py`，经白名单校验、200 KiB 上限下载并内嵌为 data URI；没有、下载失败或网页解码失败时只显示昵称。自动 PDF 导出禁用网页脚本，网页的解码失败兜底不作用于 PDF。头像与真实来源链接的取值见 [MCP 工具参考](references/scys-mcp-tools.md)，不得按 ID 猜原文 URL。分享给社区外的人之前，请留意手册中其他会员的昵称与头像。

## 0.10.1 生成说明与竖长配图

步骤标题改用“步骤 1”等写法，与站内来源 S1 区分；判断步骤沿用目标、3–5 条动作和做完标准。整本源稿在书名后标明通用版或定制版。竖长图在 A5 PDF 中限高，仍需逐图核对图注是否同页；无人值守提纲、原始返回导出、可选工具、航海图片主机、存档验证页与本次重导出覆盖均补了操作说明。

## 0.10.0 手册结构：阅读说明 → 路线图 → 主线 → 附录

按已认可的样稿固定整本手册的结构。篇幅以更细更全为先，可读性靠结构解决，不靠删信息，不设页数或字数上限。开头依次是模板自动目录、阅读说明、路线图，然后才是条件或读者画像；路线图替代旧版“现在先做什么”。每章开头 2–3 行写解决什么、做完是什么样；正文只留主线步骤，对照表、官方规则摘录、模板、案例卡集中到附录，原位留跳转；同一段意思只保留一处。取资料的过程（如网站拒绝程序访问、改读网页存档）只写进来源节与资料记录；官方规则先读当前页面，读不到才用存档并写快照日期。

文件检查新增：源稿手写“目录”标题、阅读说明排在路线图之后、开头不是阅读说明紧接路线图会失败；有阅读说明却没有路线图、路线图缺页内链接或缺“先不做／以后再看”一句、来源节之外出现取数过程字样会提醒。虚构示例改为同样的开头。PDF 书签沿用导出脚本的默认设置，无须额外参数。

## 0.9.0 写作质量与手机 PDF

先判定定制版或通用版；阅读说明集中风险与限定。步骤改为目标、动作清单和做完标准；按素材核案例卡、总结性做法及可套用模板，避免只写短摘要。正文来源标记和文末条目双向可点，连续来源合组；文件检查核悬空锚点和通用版误用个人称谓。PDF 改为更窄的页面与更清晰的字号、表格折行，供手机阅读；Markdown 和网页留在本地，飞书仅上传 PDF。

## 0.8.4 配图与 PDF 导航

写作前在现有 `plan.md` 对每个关键动作选真实截图、依据已核实规则的原创示意、明确虚构的样例预览或纯文字；纯文字记录为什么足够，不设最低图数。已画好的纯 SVG 可用本机 `scripts/render_diagram.py` 转成高分辨率 PNG，SVG 和 PNG 都留在手册 `images/`，网页/PDF 则内嵌 PNG；不画未经核实的平台后台界面。图注标“教学示意”、来源、日期和适用边界，并与图片同处 `<figure>`。文件检查对正文 0 图、或图片缺同一 figure 内非空图注给非阻断提醒，交付前人工核清晰度、可放大和 PDF 图注同页。自动 PDF 增加无页码的可点击打印目录，并在支持的 Chrome 中增加章节级书签；旧版浏览器仍保留可点击目录。

## 0.7.0 增加

## 验证范围

历史版本记录：截至 2026-09-22，0.5.0 已做 24 个合成回归检查，涵盖零图片/零未知项、真扁截图、关键步骤遗漏、证据缺失、正文或原文变更后核对失效、真实试用记录缺范围、保留历史评分等。它们验证程序行为，不代表 0.6.0 完整手册质量。

旧的小红书、视频号、X 手册重新经过新版文件检查：文件通过；没有针对新版的完整内容核对记录，因此分别报告内容未复核、真实试用未测，不再沿用旧“全部通过”结论。

另外完成两项独立合成行为测试：信息不足的 X 请求先补问目标与条件；已有手册从每天两小时改成一小时，保留 120 分钟总工作量并拆成两晚各 60 分钟，未受影响的三节保持原文，五个原始文件副本哈希一致。记录明确真实试用未测。测试发现局部修改与“不采用做法”参考的章节要求有冲突，已收窄为只处理相关内容，并核对文本一致性。

整套 0.6.0 尚未使用真实普通会员账号从检索到交付跑完，也没有真实新手完整试用记录。各浏览器的实际打印效果、飞书或微信应用内打开效果，以及真实 AI 客户端按新 SKILL.md 生成网页的效果均未验证。`examples/` 的内容是虚构演示，不是实测成效；详情页真实截图仍需人工拍摄并标注版本与范围。

历史验证：0.2.0 生成过小红书手册；0.3.0 生成过视频号和 X 手册；0.4.0 修复部分检索、图片、规则分类问题。这些记录和旧评分保留在内部测试目录，不能当作 0.5.0 的完整通过证明。以往整本测试约耗时 45–58 分钟；本版没有承诺固定耗时或实测提速比例。
