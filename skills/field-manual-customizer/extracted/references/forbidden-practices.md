# 不写进手册的做法

## 怎么判断

站内帖子、甚至官方航海手册里，都可能夹着下面这几类做法。**只要属于其中一类，就不写进操作步骤**：

- **造假**：假交易、假评价、假咨询、假发货
- **躲平台检测**：改文件信息、去水印、多开换 IP、换着法子藏无货源
- **用别人的东西**：直接用别人原创实拍的图、用 AI 洗别人的图
- **坑买家、坑读者**：让买家退不了货、用钱换删差评；收了钱的推广不标明是广告

判断不了的，先按「不写」处理，在交付时告诉用户这一处拿不准。

## 具体做法

以下是 2026 年实际遇到过的，分电商和内容、自媒体两类。其他平台的同类做法照此处理。

「为什么不写」一栏是检查线索，不是现行平台规则。写进手册时，处罚须核对本次取得的适用官方原文；只有站内转述就标为转述。找不到原文，明确已核到的行为和未核的规则，不编具体处罚，也不保证一定会被处罚。下表不能当出处。

| 做法 | 为什么不写 |
| --- | --- |
| 刷单、补单、自己或朋友下单冲销量、拍单冲店铺等级 | 平台判为虚假交易：可冻结店铺资金、限制提现、扣保证金、延期结算 |
| 发空包；先发一个礼品单占住单号，等真货发了再改单号 | 属于虚假发货，要赔钱扣分 |
| 找人代拍代评、买评价、用小号在评论区晒「已买」 | 虚假评价 |
| 用自己其他账号或朋友假扮顾客刷客服回复率；伪装顾客去同行店铺套话术 | 制造虚假数据，扣的分比想提的分更多 |
| 去掉 AI 图的明水印、暗水印，伪造 EXIF、改文件名、加噪点来躲 AI 识别 | 故意绕开平台识别，本身就是在躲规则；平台对 AI 内容的具体要求，引用前找到平台原文 |
| 用比特浏览器等多开工具、买代理 IP 做一堆账号 | 平台在查这类批量做号 |
| 把「让供应商手工打单」的理由写成「不被平台查到无货源」；把买家手机号里的数字换成字母躲检测；用中转仓二次换面单 | 这是在教怎么藏，不是在教怎么把货源关系理顺 |
| 从拼多多、淘宝、抖音拍单，再把单号填回来冒充发货 | 平台查无货源的一个办法就是看快递单号 |
| 商品图、笔记里带微信号、电话、网址，或私信把人拉到微信成交 | 站外引流，最重可永久封号 |
| 直接扒别人原创实拍的图用；拿别人的原图让 AI 二次生成 | 侵权，被投诉时没有办法举证 |
| 把退货地址填成买家退不了的地址 | 坑买家，会被投诉和处罚 |
| 用红包、返现、补偿换删差评；聊天里写「好评返现」 | 等于把违规证据交给平台 |

**内容、自媒体方向**（视频号、X 等测试里遇到的）：

| 做法 | 为什么不写 |
| --- | --- |
| 拿别人爆款的逐字稿改几个字，用 AI 洗稿，「去重」「过查重」 | 用别人的东西，还在躲平台的原创检测 |
| 直接搬运、翻译搬运别人的视频或帖子 | 用别人的东西；平台的原创判定会查 |
| 用别人视频的原声、克隆别人的声音 | 用别人的东西 |
| 下载盗版电子书、课程当素材 | 侵权 |
| 买粉、刷播放、刷赞；花钱或发红包找人点赞、转发、评论；互关互赞群 | 造假数据 |
| 代开认证、买卖账号；买住宅 IP、伪装所在地注册或养号 | 躲平台检测 |
| 接商单、做分佣，内容里不标明是广告 | 坑读者；平台一般有付费合作要标注的规定，写进手册前找平台原文 |

学对标账号的选题、结构、节奏可以；照着别人的文案改写、照搬别人的画面不行。

## 手册里怎么写

**新手册确实引用了含这些做法的材料时**，在相关步骤前说明不采用什么、为什么；多处影响整条路线时，可在开头集中说明。没有相关内容时不必新增这一节。局部调整或规则更新只处理受影响的做法，不为满足目录格式加无关章节。

**原帖或原手册里夹着这些做法时**，只取合规的部分，在那一步的提醒里写：

> 原帖此处还有一段教某某做法，属于某某，本手册不采。

**有正规替代做法的，写替代做法。** 例子：

| 不要 | 改成 |
| --- | --- |
| 刷客服回复率 | 打开商家 App 的消息提醒，设好快捷话术和关键词自动回复 |
| 用 AI 图躲识别 | AI 图只用来自己判断要不要拿样；公开发布时按平台要求主动标注。平台怎么要求、标了会不会影响流量，引用前找到平台原文，找不到就进自查清单 |
| 用返现换删差评 | 先把退款、补发、换货真正做完，再不带任何条件地请对方修改评价；或者按平台的正规申诉流程走 |
| 找朋友刷销量 | 按正常节奏发内容测品，用手册里带数字的线判断要不要换品 |
| 改写别人的爆款文案 | 从一手材料里拿内容（书、自己的经历、官方数据），学对标的选题和结构；说清这样起步慢在哪 |
| 买粉、互关互赞 | 多去同领域的大号下面认真评论，发能被收藏、转发的内容 |

**本次读到的多篇材料含同一类不采用的做法时**：按实际阅读范围写明哪些作者或材料这样做、为什么不采用；不把搜索样本扩大成“站内主流”或“多数人”。给出有依据的替代做法，说明限制和是否找到真实结果；推测的速度差异明确标为推测。
