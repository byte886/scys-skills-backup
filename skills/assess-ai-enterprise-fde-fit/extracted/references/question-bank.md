# 结构化题库

## 使用方法

评分题采用1–5分：1=完全不符合，2=较不符合，3=不确定/一般，4=较符合，5=非常符合。要求用户按最近12个月的真实行为回答，不按理想中的自己回答。开放题没有标准答案，允许关键词、短句、“不知道”或“没有”。

题目最多每轮3道。标准模式用8组完成24个核心问题，每组混合评分题和开放题，避免连续问卷：

| 组别 | 题目 |
|---|---|
| 第1组 | Q01、Q02、O01 |
| 第2组 | Q03、Q04、O02 |
| 第3组 | Q05、Q06、O03 |
| 第4组 | Q07、Q09、O04 |
| 第5组 | Q10、Q11、O05 |
| 第6组 | Q13、Q15、O06 |
| 第7组 | Q16、Q17、Q18 |
| 第8组 | Q19、Q21、Q23 |

快速模式使用Q01、Q03、Q05、Q07、Q09、Q11、Q15、Q19和O01、O02、O04、O05。深度模式使用Q01–Q24和O01–O08；Q25–Q30只在相关能力需深挖时追加，不机械全问。

## 题目

| 编号 | 题目 | 主要测量 |
|---|---|---|
| Q01 | 我能独立把一个AI想法做成别人可以实际使用的成果，而不只是演示。 | AI交付/技术实现 |
| Q02 | 我做过的AI项目有真实用户、使用记录或可展示成果。 | AI交付/案例 |
| Q03 | 我能说明一个AI方案替客户节省了多少时间、成本，或提升了什么结果。 | 量化结果/商业成熟 |

| Q05 | 我熟悉至少一个行业的业务流程、岗位语言和主要经营指标。 | 行业理解 |
| Q06 | 面对客户提出“做个智能体”时，我会先追问业务目标、使用人和验收指标。 | 需求翻译 |

## 开放题

| 编号 | 问题 | 引导提示 | 主要用途 |
|---|---|---|---|
| O01 | 在你最熟悉的企业或岗位里，人们每天最重复、最费时间或最容易出错的工作是什么？如果只能选一个，你最想先改造哪一项？为什么？ | 可以写招聘筛选、客服答疑、内容改写、报表整理等；不知道也可写“暂时想不到”。 | 行业经验、痛点意识 |
| O02 | 请讲一个你主动解决过的真实问题，不一定与AI有关：当时谁遇到什么问题，你做了什么，结果怎样？ | 工作、创业、社群或个人项目都可以。 | 迁移能力、所有权、结果意识 |
| O03 | 假设客户只说“我想做个AI助手”，你最想先问他哪三个问题？ | 不要求专业术语，按自己的理解回答。 | 需求翻译、业务判断 |
| O04 | 如果要找到前10位潜在客户，你会从哪里找到他们？你愿意怎么开口？ | 老同事、朋友、社群、商会、内容平台都可以。 | 客户触达、销售意愿 |
| O05 | 在讲师、顾问、方案设计、动手实施、驻场FDE、持续运营中，你最想做哪两类？最不愿意做什么？为什么？ | 可按喜欢程度和生活限制回答。 | 角色偏好、工作方式 |
| O06 | 如果只给你7天为一家企业做一个小项目，你愿意交付什么？哪些内容明确不做？客户怎样判断你做成了？ | 想不到时可先描述熟悉行业，由机器人提供选项帮助完善。 | 产品化、边界、验收 |
| O07 | 讲一次项目出错、延期或需求变化的经历：你怎么发现、处理和复盘？ | 没有AI项目也可讲其他工作项目。 | 调试、抗压、项目管理 |
| O08 | 未来90天你愿意完成什么真实作品、客户访谈或付费案例？你能投入哪些资源？ | 目标尽量可检查。 | 行动意愿、资源约束 |

## 开放题分析规则

- 不按写作能力、篇幅或“答案漂亮程度”打分。
- 提取事实：熟悉的岗位、具体问题、受影响的人、损失、用户采取的行动、结果和限制。
- 提取想法：用户喜欢的角色、不愿承担的工作、服务边界和客户入口。
- 将开放题作为结构化分数的解释、证据修正和方向生成依据，不另设神秘加分。
- 回答抽象时，给2–3个贴近其行业的选项帮助思考，再允许用户选择、修改或写“都不是”。
- 用户说“不知道”时，提供微教学后继续，不把“不懂企服术语”误判为能力差。

## 必做证据追问

完成题目后，最多一次问3个：

1. 请选一个最能代表你的AI项目：为谁做、解决什么问题、最终交付物是什么？
2. 这个成果是否真实使用？有无前后数据、截图、链接、反馈或复购？
3. 如果明天要出售它，你能否说清价格、周期、客户配合和验收标准？

若FDE是可能主路线，再追问：是否能读写代码/接口、如何处理一次真实故障、能否接受驻场或高频客户协作。

## 一致性检查

- Q01/Q02高分但没有任何可描述成果：降低证据等级，不直接指责。
- Q09高分但列不出决策人来源：客户触达最多按E1。
- Q13/Q14高分但没有交付清单或模板：产品化最多按“已有雏形”。
- Q19低分：即使技术高，FDE也应提示工作方式不匹配。
- Q22低分：企服创业路线提示现金流风险，但不影响受雇FDE技术适配。
