# scys-deep-tutorial · 生财深度调研教程工作流

把「提出一个问题/方向 → 检索生财站内资料（scys-mcp）→ 结合世界知识与联网补充 → 结构化 → AI 亦仁 + AI 刘小排双导师点评 → 逐条修订 → 图文并茂单文件 HTML 教程」封装成的通用 skill。已去除任何个人背景与私有路径，可直接分享。

## 安装

把整个 `scys-deep-tutorial/` 目录复制到 agent 的 skills 目录即可被发现（ZCode 默认 `~/.agents/skills/` 或项目 `.agents/skills/`）：

```bash
cp -r scys-deep-tutorial ~/.agents/skills/
```

**前置**：需已配置生财 MCP（scys-mcp）。无该 MCP 时 skill 会要求显式降级（纯世界知识+联网版、无双导师），不会冒充流程。

## 调用示例

```text
把「AI 编程接单怎么起步」做成教程
调研一下生财站内关于「虚拟资料项目」的打法，出一份图文教程
把 XX 这位圈友的精华帖做成教程
把《微信小程序产品打造》航海手册做成教程
```

可选参数（口头带上即可）：素材范围（人物/手册/关键词/时间窗/仅精华）、学习者背景（会匿名化）、深读篇数、输出目录、是否允许联网补充。

## 输入 / 输出

- **输入**：一个主题或问题（必填）+ 上述可选参数。
- **输出**：`<输出目录>/` 下——终版 HTML（`YYYY-MM-DD-<主题>-教程-AI双导师点评版.html`）、初稿存档、候选索引、深读笔记、双导师点评全文与会话 ID；assets 图片目录仅在你明确确认下载图片时才创建。
- **安全边界**：默认零外部下载、默认只读——站内图默认以 CSS 绘图 + 文字卡 + 原帖链接呈现；点赞 / 投锚 / 收藏等写操作均需你逐项确认后才执行。
- **完成判定**：验收清单通过 + 知识结构七要素齐全（含收尾「关键/难点/障碍/误区」四节）+ 双导师点评并逐条修订（R1-Rn 记录）+ 全部素材可溯源。
