# 阶段 8：验收清单 + 坑位手册

## §1 静态程序化检查（必做，写脚本跑）

1. **标签配对**：解析 HTML 统计 `<section>` / `<div>` / `<table>` 等开闭数量一致（用替换法改过内容的重点查）。**计数前先剥离 HTML 注释**——注释里的组件示例标签会干扰计数。
2. **锚点**：目录中每个 `href="#sN"` 都有对应 `id`，且目录文字与章节标题一致。
3. **图片**：每个 `<img src>` 指向的文件存在且非占位图；无死链。
4. **占位符残留**：全文 grep `TODO` / `{{` / `【待补】` 等。
5. **外链与数据说明**：站内链接格式正确；「数据说明」节含取数时间窗、检索词、深读清单。

## §2 渲染验收（推荐，有 Chrome + Pillow 时执行）

- Chrome headless 截图 + PIL 扫描空白段：
  - 预计高度 >6 万 px 的长文档：**按章拆分为多个分页 HTML 分别渲染再切片检查**。Chrome 单页绘制高度上限约 10.5 万 px，超限会在截断处静默收尾（无报错）；拆分页渲染后图片高度计入，同版式高度比裂图态高 50%+ 属正常。
  - **临时分页 HTML 必须放 assets 同级目录**——放 /tmp 会让相对路径图片全裂。
  - 空白判定：浅背景 + 白卡片版式下，判「内容行」用行内**最暗像素 rowmin<200**（不能用 rowmax——白卡片行恒为 255，会整页误判）。
  - x 步进 12–24 稀疏扫全页；发现疑似空白段必须**密集复扫（x 步进 1–4）再定性**——稀疏步进会把稀疏细字行误判为空白（假阳性先复核再改）。
  - numpy 不可用（架构不匹配等）时用纯 PIL `getpixel` 步进扫描（x 步进 16–24、y 步进 8、提前退出，性能可接受）。
- 全过 → 删除渲染临时文件，只留终版。

## §3 图片与素材边界（默认零外部下载）

**总原则：默认不下载任何外部资源。** 教程默认不发起任何外部网络请求：站内图片一律以「CSS 原生绘图 + 文字转述卡 + 站内原帖链接」呈现，产物零外部请求、信息不丢。仅当用户**明确确认具体图片清单**后，才通过受控的已授权工具获取该批图片；获取时不手工拼接 / 转写 / 复述任何带签名的完整访问 URL 或参数，产物、笔记与日志中只记录来源 ID + 序号；**任何获取失败统一降级为文字卡**并在数据说明注明。

以下坑位仅在「用户已确认获取」的分支里适用：

| 坑 | 现象 | 处置 |
|---|---|---|
| 占位 WebP | 获取「成功」但实为约 2844 字节、1280×67 的占位图（源站对失效引用不报错，源头图已丢，重试也一样） | 获取后 md5 去重 + `file` 验格式；占位图删除对应 `<figure>` 降级文字卡 |
| 请求被拒三形态 | 400（缺访问凭证）/ 403（签名校验不匹配）/ InvalidArgument（源端签出的处理参数串自身非法） | 先试一张做诊断实验；确认是批量性问题后**整批一次性降级 CSS 文字卡**，勿反复重试变体 |
| 断点拼接 | 分段读长文时图片引用被截断 | 上下段拼接去重重叠字符（仅用于判断该节是否有图，不落盘完整带签名的访问地址）；`file` 可检出异常文本 |
| 飞书登录墙 | 正文外链匿名访问被拦 | 如实标注，不猜内容 |
| 手册权限锁 | 「本内容限已报名船员访问」 | 用官宣帖 + 精华复盘帖替代构建，全程标注；日后解锁可做增量补章 |
| 图片序号 | 批量命名序号错乱、与索引对不上 | 统一两位补零（`-01.webp`）后再入索引 |

## §4 数据与工程坑位

- **MCP 限流**：约 40 次/分钟；`contentSearch` 有用户维度约 2 秒冷却，多分区取数分批调用；子代理别开太多并行。
- **searchTopic 结构**：返回包装对象，帖子字段在 `items[i].topicDTO` 下；固定不返回飞书合并全文，需全文走 `topicDetail`。
- **数字分身偶发不生成记录**：3 次轮询为空 → 换措辞重新 start 新会话（见 mentor-review.md §1–§2）。
- **zsh 变量循环不做分词**：`for k in $keep` 会把整个字符串当单个词，白名单失效导致批量删除误删——zsh 脚本里用数组或 `${=var}` 强制分词；**删除类操作先 `echo` 演练再执行**。
- **收尾自查**：渲染临时文件已删、notes/ 归档齐全（候选索引 / 深读笔记 / 双导师点评全文 / 会话 ID）、终版命名含日期与「AI双导师点评版」、向用户汇报时给终版文件路径与验收结果。
