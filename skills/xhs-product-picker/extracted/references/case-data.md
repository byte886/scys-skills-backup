## 10种爆款模式

### 1. 万物皆可指南/攻略/知识库
任何个人经历都能打包。指南=操作手册，攻略=带观点的玩法，知识库=系统化可检索信息。素材来源：自己的经验、YouTube/播客/外网内容策展、两者混合。

**代表案例**：装修避坑指南6802份/12.8w、杭州旅游攻略4410份/13.2w、蒙氏育儿中文宝典778份/3w（海外内容翻译策展）、纳瓦尔访谈逐字稿1000+份（YouTube单视频策展）

### 2. 极度垂直
不卖品类，卖具体场景和具体岗位。越窄越好卖。

**代表案例**：京东采销面试906份/20w（只做一个岗位方向）

### 3. 避坑 > 推荐
焦虑比欲望更驱动付费。"避坑"两个字就是转化率。

**代表案例**：装修避坑指南6802份/12.8w、韩国皮肤科避雷15000份/26w、提车验车清单、日本生活防坑指南39元/份

### 4. 策展重组
筛选+排序+解读=新价值。帮用户省搜索和判断时间。

**代表案例**：审计师装修索引5536份/43.7w、品牌档案合辑166份、Reddit英语热帖阅览室

### 5. 痛点清单化
把模糊焦虑变成具体checklist。

**代表案例**：备婚清单7429份、待产包清单229份

### 6. 抄捷径
帮人用更少努力达到效果。

**代表案例**：50个故事记住5500考研单词（暗黑版）、面试话术模板

### 7. AI+垂直场景
AI工具×具体需求。有开发能力或想做差异化时用。

**代表案例**：AI面试助手15000份/420w、自研英语AI学习网站9465份/47w

### 8. 情绪/身份消费
帮人认识自己/表达身份。

**代表案例**：吸引力愿景板1771份/7w、MBTI指南

### 9. 低价获客→后端升单
前端0.1-9.9元引流品，后端服务/实物变现。

**代表案例**：肌肤报告0.1元→到店消费、心理测评0.9元、宝宝起名0.1元/3万单→私域高价起名服务

### 10. 物理+数字组合
加打印版/手稿/咨询提高感知价值。

**代表案例**：保险话术打印版189份、运营课手稿6473份/77w

## 指南（Guide）写法规律

> 从40+条指南类案例中提炼出来的写作模式。指南的本质：**把一个具体场景里的隐性知识，变成别人能跟着做的步骤。**

### 6种切入点模式

**① 避坑/反推荐型**（"我替你踩过了"）
用户买的是安全感。不是告诉他"怎么做好"，而是告诉他"哪些一定不要做"。
- 装修避坑指南6802份/12.8w
- 韩国皮肤科避雷15000份/26w
- 日本生活防坑指南39元/份

**② 身份锚定型**（"你是谁，决定了你需要什么"）
用具体身份标签锁定目标用户，比如"新手AE""住院医""INFP"。
- INFP高敏感成长知识库29.9元/141单
- 住院医专用笔记本医嘱速查手册7.9元/1098单
- 刺头学生治理手册（含家长）19.9元/1188单

**③ 场景极度具体型**（"这件事只在这个时刻发生"）
越具体越值钱。不是"装修攻略"，是"刚拿钥匙还没找装修公司那两周的必读内容"。
- 牛奶蛋白过敏脱敏手册39.9元/378单
- 提车验车清单
- 待产包清单229份

**④ 痛点打包型**（"一篇文章解决你全部的X"）
一个特定痛点下的所有解法打包。用户是"我全都要"心态。
- 10万字跨境电商一人DIY手册249元/513单
- 保险营销话术合集81元/189份

**⑤ 极简入门型**（"别怕，我把门槛拆掉了"）
面向门外汉，主打"不需要任何基础"。用户买的是"我能行"的信心。
- App独立开发者入门指南68元/307单
- 考研单词50个故事版

**⑥ 视角独特型**（"换个角度看同一件事"）
同一个领域，用别人没试过的视角切入。不跟竞品比全，比"我只看这一个点"。
- 审计师装修索引（审计师视角看装修）79元/5536份/43.7w
- 万物隐喻创作思维知识库（创作者视角看隐喻）158元/683单/10.8w

### 标题公式

```
[身份/视角] + [具体场景] + [指南/攻略/避坑/手册] + [量化信号]
```

示例拆解：
- "审计师博主"（身份） + "装修"（场景） + "索引笔记"（形态） + "100+表格"（量化）
- "住院医"（身份） + "医嘱速查"（场景） + "手册"（形态）
- "日本"（场景） + "防坑"（痛点） + "指南"（形态） + "200条经验"（量化）

### 详情页3段结构

1. **痛点共鸣**（第一段）：描述"你正在经历什么痛苦"，用户读前3句就觉得"这说的就是我"
2. **为什么是我**（第二段）：交代作者的经历/踩坑/试错，"我帮你走过这条路了"
3. **你能得到什么**（第三段）：具体交付物+量化信号，不写"干货满满"，写"包含37个场景的提问话术和5个可直接套用的回复模板"

## 知识库（Knowledge Base）写法规律

> 从25+条知识库类案例中提炼。知识库与指南的核心区别：**指南是"我带你走一条路"，知识库是"我给你一个随时能查的系统"。**

### 5种知识库模式

**① 策展重组型**（"信息都在，我帮你挑了最好的"）
核心能力：知道哪里有好内容，并且能筛选、排序、分类、加解读。对某个领域的持续关注本身就是壁垒。
- 审计师装修索引79元/5536份/43.7w（上百份资料筛选+审计师视角解读）
- 浮光之镜艺术图书馆109元/1250单/13.6w（艺术领域优质内容策展）
- 油管日语素材知识库49元/10000单/49w（油管素材结构化+个人见解）
- 蒙氏育儿中文宝典39元/778单/3w（海外蒙氏资料翻译+策展重组）
- 全球经典好书精读知识库15.6元/813单/1.3w（读书拆解+AI辅助）
- 海外产品营销全体系知识库74元/171单/1.3w（海外营销工具/方法论/平台策展）

特点：外部素材为主，策展人的筛选眼光和解读能力是核心价值。

**② 人物策展型**（"一个名人的全部思想，帮你整理好了"）
选一个有深度但资料分散的人物，把他的播客/文章/演讲/书做系统整理。人物本身就有粉丝基础。
- 纳瓦尔知识库119元/495单/5.9w（播客+文章+思维模型+AI纳瓦尔互动）
- 李小龙哲学解读合集59.99元/245单/1.5w（李小龙哲学思想系统整理）

特点：名人IP自带搜索量，用户买的是"不用自己去翻100个视频"。

**③ 职业/岗位知识库型**（"这个岗位的所有东西，打包给你"）
聚焦一个岗位，把该岗位需要的知识、技能、话术、SOP、模板全部打包。核心竞争力：你在这个岗位上干过，知道什么重要什么不重要。
- 班主任工作流知识库256元/1322单/33.8w（班级管理+班会+沟通SOP）
- 金融银行人职场知识库49.9元/69单/3443（知识+社群+工具）
- 达人BD推品技巧29.9元/399单/1.2w（BD全流程SOP）
- GTM专业知识手册15.9元/1122单/1.8w（GTM岗位知识体系）
- 独立老师工作管理系统模板69元/849单/5.9w（老师管理SOP模板）

特点：工作经验产品化，岗位越细分越值钱。

**④ 系统/工具型**（"打开就能用的工作台"）
交付的不是文档，是一个搭建好的系统（飞书/Notion），用户打开就直接用。游戏化设计降低行动门槛。
- 灵澄岛人生管理系统89元/923单/8.2w（飞书系统+游戏化+社群）
- Notion×AI主体性进化系统999元/136单/13.6w（7阶段游戏化+AI洞察）
- 心流打卡系统89元/448单/4w（打卡系统+显化理念）
- 情绪疏导系统69.9元/511单/3.5w（课程+练习+社群）
- 全屋空间整理收纳系统课79.9元/447单/3.5w

特点：交付平台是飞书/Notion，卖的是"不用自己搭建"和"社群归属感"。

**⑤ 方案/灵感集型**（"100个现成方案，直接拿去用"）
针对某个重复性需求，给大量现成方案。用户买的是"不用每次自己想"。
- 100个艺术活动疗愈方案39.9元/422单/1.7w
- 万物隐喻创作思维知识库158元/683单/10.8w（创作者的隐喻素材库）
- 品牌档案合辑59元/166份/9794

特点：数量信号是核心卖点（"100个""万物"），用户买的其实是"抄作业权"。

### 知识库 vs 指南：选哪个？

| 维度 | 指南 | 知识库 |
|------|------|--------|
| 结构 | 线性阅读，step by step | 网状检索，可查可搜 |
| 规模 | 单一角度走到底 | 多角度系统化打包 |
| 交付 | PDF为主 | Notion/飞书为主 |
| 定价 | 9.9-39.9元 | 39.9-256元 |
| 更新 | 一次写完 | 承诺持续更新 |
| 素材 | 个人经验为主 | 外部策展+个人经验 |
| 用户心理 | "带我走一次" | "给我一个随时能用的工具" |
| 适合场景 | 一次性问题（装修、旅游、备婚） | 持续性需求（职业成长、学习、创作） |

**判断标准**：用户是一次性决策（买完走人），还是需要持续参考（买完还会回来查）？前者做指南，后者做知识库。

### 知识库标题公式

```
[范围/身份/人物] + [知识库/系统/宝典/索引] + [平台信号]
```

常见平台信号："基于飞书""Notion模板""打开就能用""持续更新""一站式"。

### 知识库3大价值主张

- **省时间**："信息都在，我帮你挑了最好的" → 省掉用户的搜索和判断成本
- **可依赖**："打开就能用，不用自己搭建" → 省掉用户的学习和实施成本
- **不落伍**："承诺持续更新" → 省掉用户担心过时的焦虑

## 核心逻辑

> 不要卖产品品类，要卖付费场景。
> 不要说自己卖"装修攻略"，要说你在卖"一个刚买房的人不被装修公司坑的安全感"。

**定价关键不是成本，是感知价值。** 同一份PDF，叫"XX指南"卖9.9元，叫"XX避坑手册+可打印清单+配套模板"卖39.9元。

**小红书上30元以下是"为什么不呢"心理价位**——用户几乎不用犹豫。
