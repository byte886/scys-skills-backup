# base-bili-script-writing

## 适用场景

当用户已经有商品排序，需要生成一版可以口播的中文脚本时，使用本 skill。

这个 base_skill 的教学目标是：让学习者理解脚本生成不是堆卖点，而是把商品信息转成有顺序、有场景、有提醒的表达。

## 需要输入

- 商品排序表
- 视频主题
- 目标观众
- 预计时长
- 语气风格
- 必须讲到或不能讲的内容

## 执行步骤

1. 先确认视频主题和观众场景。
2. 写一个 10 到 20 秒的开场，直接说明这期解决什么问题。
3. 按排序逐个写商品段落，每个段落包含：
   - 适合谁
   - 解决什么问题
   - 关键卖点
   - 购买前提醒
4. 写一个收尾，总结适合人群和选择建议。
5. 检查商品数量、商品顺序和已知事实是否一致。

## 输出格式

```markdown
## 口播稿

### 开场
...

### 商品 1：商品名
...

### 商品 2：商品名
...

### 商品 3：商品名
...

### 收尾
...

## 使用提醒

| 项目 | 说明 |
|---|---|
| 需要补充素材 | ... |
| 不能确认的信息 | ... |
| 建议人工复核 | ... |
```

## 质量检查标准

- 商品顺序必须和排序表一致。
- 不新增未提供的价格、参数和效果承诺。
- 每个商品段落都要有场景、卖点和提醒。
- 语言要适合口播，句子不宜过长。
- 输出应能被下一步脚本检查直接审阅。

## 简单示例

输入：

```text
主题：租房厨房电器推荐。顺序：空气炸锅、电饭煲、即热饮水机。风格：实用、克制、像朋友推荐。
```

输出要点：

- 开场聚焦租房厨房空间小。
- 每个商品讲一个明确使用场景。
- 对价格未知或参数未知的内容标注需要人工补充。
